# 系统资源历史与卡顿回放

`liu-bigpc` 使用 atop 在后台每 5 秒记录一次系统和进程活动，按天写入
`/var/log/atop/atop_YYYYMMDD`。覆盖 CPU、内存、swap、磁盘 I/O 和系统 PSI；
atopacct 补充采样之间已退出进程的记账信息，但不能恢复它们所有详细指标。
暂不采集 GPU 或每进程网络流量；整机网络统计仍可查看。

配置位于 `nixos/hosts/liu-bigpc/default.nix`，仅影响这台 PC。
后台间隔由 `/etc/default/atop` 的 `LOGINTERVAL=5` 控制，`/etc/atoprc` 的 interval
只设置交互默认值。`LOGGENERATIONS=7` 使用上游按文件修改时间清理的逻辑；
每天轮转或服务启动时删除超过保留阈值的旧文件，实际可能保留约 8–9 个日期文件，
不是严格的七天或容量上限。运行一两天后用 `sudo du -sh /var/log/atop` 检查大小。
日志目录权限 0700，记录服务 UMask=0077；日志仅存本机，不随文档镜像传输。

## 生效及检查

Agent 只构建验证，不执行工作站 switch。用户在普通终端执行：

```bash
cd /home/liou/nix-tools
nu rerun.nu liou --host liu-bigpc
systemctl status atop atopacct --no-pager
systemctl list-timers atop-rotate.timer
sudo cat /etc/default/atop
sudo ls -lh /var/log/atop
```

等待十几秒后再次查看当天文件，应持续增长。若服务失败：

```bash
sudo journalctl -u atop -u atopacct -b --no-pager -n 80
```

从生效时开始积累历史，无法补录此前卡顿。

## 卡顿时记时间，恢复后回放

卡顿发生时记住右上角时钟时间；能操作终端时可运行 `date -Is`。
回放使用本机时区，以当日日志和时间为准：

```bash
# 今天的历史
sudo atop -r

# 示例：2026-10-18 21:30–21:35
sudo atop -r /var/log/atop/atop_20261018 -b 21:30 -e 21:35
```

常用按键：`t` 下一帧、`T` 上一帧、`b` 跳到时刻、`q` 退出；
`C` 按 CPU 排序、`M` 按内存排序、`D` 按磁盘活动排序；
`d` 切换进程磁盘视图，`m` 查看内存视图，`c` 查看进程命令行，`h` 看帮助。
最初一帧通常是开机累计值，应重点看随后 5 秒的区间。

也可以输出适合对照的文本报告：

```bash
# 压力、磁盘及换页历史；日期和时段换成卡顿当天
sudo atopsar -r /var/log/atop/atop_20261018 -b 21:30 -e 21:35 -B -d -s
```

重点把同一时刻的指标放在一起看：

- CPU 总量不高，但某个核心跑满：可能是单线程瓶颈。
- I/O PSI 升高、磁盘延迟或队列升高：检查当时读写最多的进程。
- 内存 PSI、换出/换入升高：检查内存回收及工作集；swap 已用量本身不能证明正在换页。
- 上述均正常而桌面卡顿：继续检查 Niri、GPU/驱动和应用日志；atop 无法覆盖所有图形故障。

5 秒采样可能平均掉更短的尖峰。不要只按读写量最大就认定责任进程，
还需结合延迟、压力、后台内核活动和卡顿时间。下次分析提供卡顿日期、起止时间及
上述报告即可；原始日志和命令行可能含私人路径，留本机分析。

处理优先级：

1. 给代码搜索限定具体仓库/子目录、文件类型，确认忽略规则覆盖构建产物，避免无界遍历
   整个机械数据盘或依赖缓存；不要无差别删除、隐藏或移动源码。
2. 限制Rust构建并行度，并把同时进行的多个构建合并考虑。可用Cargo的build.jobs/
   CARGO_BUILD_JOBS或-j先做对照，单任务从4–6个job试起；这不是整机总线程上限，
   编译器及其他构建仍可能并行，需复测CPU/PSI与构建时间。
3. 对换页窗口核对构建容器/cgroup的内存限制及大内存编译阶段，再决定是否调整限制、
   构建调度或缓存位置；不先盲目关swap、调swappiness或采购内存。
4. 已准备的EDA禁用转储配置只防止其完整core镜像写盘，不能代替前三项。

本次仅分析并更新文档，不修改并行度、内核参数、搜索配置或运行中任务。
原始报告和分析脚本均留本机/tmp/atop-*20261020*等路径，不随NUC文档镜像传输。
