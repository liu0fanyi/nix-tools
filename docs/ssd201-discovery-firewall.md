# SSD201 发现服务：本机防火墙

规则位于 nixos/configuration.nix，仅 networking.hostName == liu-bigpc 生效。
板卡从动态 UDP 源端口回应发现请求，不应靠普通 5000 查询的反向连接自动放行。

- eno1，源 192.168.1.88，目标 192.168.1.100，UDP 5001：客户端查询响应。
- eno1，源 192.168.1.88，目标 239.255.1.1，UDP 5000：产品 SSDP 通知。

客户端查询 socket 必须绑定 5001；sip_old 测试已固定该端口，tauri_config_page
需选择本机 192.168.1.100 和相同查询端口。端口占用时先关闭对应工具，不抢占。
不放行动态端口范围，不硬编码板卡临时源端口，不扩大到其他板卡或主机。
