# Android 同文中文九宫格

本配置针对用户选择的 Trime + 四叶草九宫格。APK和配置原包版本、URL、SHA256、官方签名指纹在 [sources.json](../config/android/trime/sources.json)，本地默认方案补丁在 [default.custom.yaml](../config/android/trime/default.custom.yaml)。官方正式APK与第三方词库/主题分开，不安装配置项目提供的debug整合APK。

手机包名 `com.osfans.trime`，已选应用专属数据目录 `/sdcard/Android/data/com.osfans.trime/files/rime`；主题 `tongwenfeng_plus`，方案 `clover_jiugong`。输入方案与键盘布局需同时匹配，单改九宫格外观不能替代方案。

## 配置与恢复

先核对包身份/签名及现有资料；已有Trime时备份它的数据目录，初次安装也保留初始化的installation.yaml和user.yaml。按sources.json下载原始APK与trime.7z，逐项校验SHA256；7z解压到临时目录。导入方案时排除installation.yaml、user.yaml、用户学习数据库、sync和build，不将上游作者的运行身份覆盖到本机。将本仓default.custom.yaml作为默认方案补丁覆盖，然后在同文主界面点“部署”，在“键盘样式→主题”选tongwenfeng_plus；“方案”应显示四叶草九宫格。后续修改先备份同名文件，不删除已有学习数据库。

本轮初始化备份在本机 `/tmp/trime-install-20261110/before-rime`，权限仅当前用户；它是临时回退备份，不是长期词库同步。上游原始安装包也只暂存在该临时目录；本仓不纳入私人词库。

回退输入法时在Android系统输入法选择器启用并选择原有搜狗；不要先卸载同文或清除数据。同文卸载前先导出资料，否则应用专属目录可能随卸载删除。

## 使用

九宫格右侧现在为“Helix”：点按进入专用控制页并将支持该协议的知识卡引擎切到normal。核心布局为前词/上/后词、左/选区/右、行首/下/行尾；“选区”切真实Helix select，随后方向键扩展选择；Esc回normal，输入切insert并返回中文九宫格。外围撤销/重做执行引擎命令，不输出z/y。通用编辑页本身仍只换键盘布局，不保证切换Helix模式。

知识卡正式手机版已接入该控制协议；本轮新配置仅在独立QA中实测，不重新安装应用。应用默认只显示输入/Esc，额外触控九宫格需主动展开。组合键契约为Ctrl+Alt+F12进入、F11返回输入、F1/F2前后词、F3/F4行首尾、F5/F6撤销重做、F10选区（全部带Ctrl+Alt）。裸F4会被Rime方案菜单截走，不能沿用裸功能键。default布局明确import_preset clover_jiugong；输入动作明确选择clover_jiugong，避免初次加载/通用默认页回退全键盘。配置修改后“部署”，若仍显示缓存布局，重新选择当前主题再回QA核对Helix标签；不清应用数据或词库。

底部大块空白：同文默认预留系统手势边衬区，并参考系统导航栏frame高度。此机已在“高级→忽略系统手势边衬区”开启后实测收起额外空白；不改系统导航模式，主题keyboardPaddingBottom保持默认0。想恢复底部避让时关闭该开关即可。

## 词库、符号与按键精简（KX）

手机继续使用官方3.3.13，不替换APK。`clover.dict.yaml`保留clover词典身份，导入既有固定Nix rime-ice包的8105/base/ext/others公共表；保留clover.base、原schema及user学习数据库，不导入巨大腾讯表。来源和逐文件SHA256见sources.json。旧clover.base/huayu没有“黄仁勋”；新词表含该词，真实手机数字九宫格48264736986已单次提交“黄仁勋”。这不是完整词汇覆盖保证。

用 `python3 scripts/prepare-trime-keyboard.py --output <新的临时目录>` 准备7份公开文件。脚本只生成候选，不操作手机；读取固定Nix包并校验SHA256。部署前备份整个手机rime目录，显式列出待覆盖文件，保留installation.yaml、user.yaml、userdb、sync及build。此次默认补丁未变，实际只覆盖词典入口、主题补丁和4张公共词表共6份，再点同文“部署”。不要整目录同步或删除旧文件。回退时还原备份的同名公开配置/词表后重新部署；不以旧学习数据库覆盖后来新增的学习记录。

空闲工具栏改为 `- : / #`、反引号及“更多”（显示方向依主题），正在组词时仍显示候选。符号通过literal commit直出，可与中文混合；左列长按额外提供英文逗号、句号、圆括号和方括号。左下“符”打开英文符号面板，长按仍打开剪贴板；“更多”使用相同动作。原主题尾部重复定义覆盖了有效动作，补丁改为独立FUNCTION动作，避免旧开关拦截。

Helix控制页现为3行15格，只有一组Esc/输入，删除误标“字词”的Tab及底部重复按键。保留前后词、行首尾、四向、选区、撤销/重做；输入返回中文九宫格。撤销/重做沿用上述Ctrl+Alt+F5/F6协议，真机正文变化与恢复已验证；本轮没有逐个触摸重测全部移动键，不扩大原验收范围。

### 九宫格拼音组合二次选择：尚未交付

目前仍是数字序列直接展开词候选。显示候选拼音注释不能实现“先选音、后选词”。核对官方v3.3.13的CandidateItemUi，现有主题没有独立可点击的拼音组合过滤条；本轮没有修改方案去伪装它。

建议交互分成两排：数字输入后先列拼音解释，例如同一个数字串的不同音节；点选某项只收窄当前候选，不向正文提交字母，保留返回全部组合的入口，下面再选词。下一步应先在隔离Rime目录验证filter/processor和候选选择回调：选音不提交正文、继续数字输入不丢组合、退格和取消可恢复、用户词频仍参与排序。只有这些成立才接入主题或前端；若必须改Trime前端，先做并行QA原型并明确官方签名/升级边界，再决定是否维护定制APK。本轮不替换官方输入法，也不把该设计记为功能实现。

本轮备份仅在本机 `/tmp/trime-kx/device/rime-before.tar`，目录0700、备份0600，含私人学习资料，请勿上传。合成QA草稿测试后原cards/drafts/edits/removals逐表相等，正式应用无写入；结果见[脱敏验收](../specs/010-host-configuration/android-trime-keyboard-results.json)。
