# NUC SIP 实验端口契约

NUC 防火墙由 `nixos/hosts/nuc/default.nix` 声明；`flake.nix` 将它与共享的 `nixos/configuration.nix` 一同加载。工作站规则不替代 NUC 规则，且不因单轮测试结束而自动过期。

仅允许测试板 `192.168.1.88/32` 从 `wlp0s20f3` 访问 NUC `192.168.1.12/32` 的 TCP 15090、UDP 18000–18101。保留原端口和工作站规则；不开放其它来源、接口或 IPv6，不自动启动 PBX。不使用十分钟临时放行脚本。地址或网卡变化时重新核对匹配条件。

用户要求先修改声明式配置，再由用户应用。Agent 不执行 switch；工作站 rerun 默认只切换工作站，不能激活 NUC。NUC 完整产物在 PC 验证后，仍须核对将要激活的整套配置，不能把未审查的其它工作树改动一并应用。

基础设施只记录主机规则；实际源、PBX、设备与 1800 秒验收的唯一计划仍为 `/data/project/xiaoqiang/esp32-p4-sip/specs/010-rtp-adf-codec/`，不在此重复建立产品任务。

回退仅移除上述两条声明并由用户重新应用；规则不会被测试结束自动删除，也不得用清理测试容器代替回退。

验证：在PC完成规则求值、NUC完整system toplevel与Home Manager generation构建；未执行系统激活。实机连通性仍未验证。规则只增加主机模块中的两条命令，不引入模块间依赖、新守护进程或额外参考。
