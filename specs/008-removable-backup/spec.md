# 可移除关键数据轮换备份

## 需求与验收

两块独立 U 盘按 UUID 识别，每份可独立恢复 Git 已跟踪/未忽略文件、未推送引用及 Zen 会话和容器配置。构建与媒体缓存排除，非 Git 目录显式白名单。

- NUL 文件清单保留特殊名称，递归备份子模块和各自 bundle，bundle verify 成功才发布。
- 被覆盖/删除内容进入历史，不无保护删除 current；原子 manifest 只在全部成功后更新。
- 缺盘、只读、满盘、拔盘不破坏上次有效备份，不自动挂载未知盘；清理限已验证 UUID 的目标根。
- Zen 退出后才复制，恢复先备份目标，不自动双向合并；Windows push/pull 后续独立实现。
- 任一盘能在另一机器读取 current 并恢复未提交文件和未推送引用；恢复演练不能只检查文件存在。

状态：候选方案，不代表已部署定时器或已选定 UUID。详细方案见 plan.md。
